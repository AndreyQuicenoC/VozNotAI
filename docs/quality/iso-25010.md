# ISO/IEC 25010

Marco de diseño. No es una certificación.

| Atributo | Decisión | Cómo se observa | Resultado |
|---|---|---|---|
| Seguridad | Autorización en servidor, hash de contraseña, cookie HttpOnly, sin clave en el cliente | Pruebas de acceso ajeno y de rol | Ver la corrida de pytest registrada en el reporte de implementación |
| Eficiencia | Un modelo en caché, una transcripción local a la vez, listados acotados | Revisión de código | No hay medición de latencia de inferencia en esta entrega |
| Fiabilidad | Estados de transcripción persistidos | Pruebas con proveedor simulado | El reinicio conserva SQLite si el archivo no se borra |
| Mantenibilidad | Capas API, servicio y repositorio | Estructura de `backend/` | Alembic aún no versiona el esquema |
| Compatibilidad | Contrato `/api/v1` | Cliente `frontend/src/services/api.ts` | El export de la raíz no usa ese contrato |
| Usabilidad | Estados de sesión, error visible, métricas reales o cero | Revisión de dashboard y login | Falta auditoría WCAG con herramienta |
| Portabilidad | Variables de entorno y Compose | `docker-compose.yml` | La imagen no incluye Whisper |

Umbral previsto para el backend: 80 % de líneas. Corrida del 2026-10-18: 31 pruebas pasando y 87 % de sentencias en el paquete `backend`. El proveedor Whisper local no entra en esa cifra de ejecución real.
